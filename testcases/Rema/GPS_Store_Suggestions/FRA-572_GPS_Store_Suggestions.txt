FRA-01 | Default suggested stores displayed without GPS fallback
    Preconditions
        User is logged in with a registered delivery address
        GPS permission not yet requested
    Actions
        Navigate to Køb & Hent checkout screen
        Wait for suggested stores to load
    Expected
        Default suggested stores endpoint is called
        3 suggested stores are displayed
        Button text shows "Vælg butik"
        GPS permission is not requested
    API
        GET /api/v3/stores/suggested - Returns non-empty list of stores

FRA-02 | GPS fallback triggered when default suggestions are empty
    Preconditions
        User is logged in
        Default suggested stores endpoint returns empty list
        GPS permission not yet granted
    Actions
        Navigate to Køb & Hent checkout screen
        Wait for default stores API response
        Grant GPS permission when prompted
        Wait for location to be acquired
    Expected
        GPS permission dialog is displayed
        Loading indicator shows while acquiring location
        Nearby stores endpoint is called with latitude and longitude coordinates
        3 GPS-based suggested stores are displayed
        Button text shows "Vælg butik"
    API
        GET /api/v3/stores/suggested - Returns empty list
        GET /api/v3/stores?filter[near_coordinates]=<latitude>,<longitude>&filter[is_click_and_collect_active]=true&per_page=3 - Returns stores near user location

FRA-03 | GPS permission denied by user
    Preconditions
        User is logged in
        Default suggested stores endpoint returns empty list
        GPS permission not yet granted
    Actions
        Navigate to Køb & Hent checkout screen

    API
        GET /api/v3/stores/suggested - Returns empty list

FRA-04 | GPS timeout handling after 3 seconds
    Preconditions
        User is logged in
        Default suggested stores endpoint returns empty list
        GPS permission is granted
        GPS location acquisition takes longer than 3 seconds
    Actions
        Navigate to Køb & Hent checkout screen
        Grant GPS permission if prompted
        Wait for 3 second timeout to elapse
    Expected
        Loading indicator shows for up to 3 seconds
        After timeout, empty state is displayed
        Button text shows "Vælg en anden butik"
        User can manually select store from full list
    API
        GET /api/v3/stores/suggested - Returns empty list
