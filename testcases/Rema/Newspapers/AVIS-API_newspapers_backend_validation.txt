Newspapers Backend & API Validation - AVIS-API

AVIS-API-01 | Verify Tjek catalogs API returns valid response structure [P0]
    Preconditions
        User has valid API key for Tjek
        Dealer ID 11deC is configured
    Actions
        Send GET request to https://squid-api.tjek.com/v2/catalogs?dealer_id=11deC
        Verify response status is 200
        Parse response body as JSON
        Validate response is an array of catalog objects
    Expected
        Response contains array of catalog objects
        Each catalog has required fields: id, ern, label, run_from, run_till, publish, page_count, offer_count, branding, dealer_id, dimensions, images, pdf_url, types, all_stores
        All field types match specification (strings, integers, objects, arrays, booleans)
        branding object contains name, website, description, logo, color, pageflip
        dimensions object contains height and width
        images object contains thumb, view, zoom URLs
    API
        GET https://squid-api.tjek.com/v2/catalogs?dealer_id=11deC - Returns catalog array with complete structure
AVIS-API-02 | Verify catalog date fields are valid and in correct chronological order [P0]
    Preconditions

        Validate all dates are valid ISO 8601 format
    Expected

        Chronological order is maintained: publish <= run_from < run_till

    API
        GET https://squid-api.tjek.com/v2/catalogs?dealer_id=11deC - Returns catalogs with publish, run_from, run_till fields
