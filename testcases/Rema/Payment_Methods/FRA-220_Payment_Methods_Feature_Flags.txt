FRA-01 | Both payment methods enabled - Happy path selection
    Preconditions
        User is logged in and has items in cart
        Feature flags app.android.payments.mobilePay and app.android.payments.worldline are set to true
    Actions
        Navigate to checkout screen
        Tap the payment method selector
        Observe the payment method bottom sheet
        Select MobilePay from the bottom sheet
        Tap confirm/continue to proceed with checkout
    Expected
        Payment method bottom sheet displays with modern UI design
        Both MobilePay and Worldline buttons are enabled and selectable
        No disabled state messages are shown
        Selected payment method (MobilePay) is applied to the order
        User can proceed to complete the order
    API
        GET /api/feature-flags - Returns mobilePay and worldline flags as true

FRA-02 | MobilePay disabled via feature flag
    Preconditions
        User is logged in and has items in cart
        Feature flag app.android.payments.mobilePay is set to false
        Feature flag app.android.payments.worldline is set to true
    Actions
        Navigate to checkout screen
        Tap the payment method selector
        Observe the payment method bottom sheet
        Attempt to interact with MobilePay option
        Select Worldline as payment method
    Expected
        Payment method bottom sheet displays
        MobilePay button shows disabled state
        Disabled message displays: "MobilePay kan ikke benyttes i øjeblikket. Benyt et andet betalingsmiddel."
        Worldline button remains enabled and selectable
        User can only select Worldline to proceed
    API
        GET /api/feature-flags - Returns mobilePay as false, worldline as true
