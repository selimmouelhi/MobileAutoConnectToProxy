        --user is logged in or guest
    Actions
        Open Butik tab
        Swipe through categories or use grid selector
        Tap on a category → View sub-category list
        Select sub category 
        Use the search bar to look for a specific product (e.g., “mælk”)
        Apply a filter { øko)
    Expected
        Categories and sub-categories are displayed correctly
        Subcategories display the right product numbers if applied
        Product list updates with correct results
        Filtered results are applied accurately
        Items have name, price, image, and label where relevant
        Empty search results are handled
Add and Remove Products from Shopping List
    Preconditions
        --Product list is visible
    Actions
        Swipe right to add an item to the shopping list
        Swipe left to remove the same item
        Check the total price and item count at the bottom
    Expected
        Item is added or removed with animation
        Shopping list total is correctly updated
        In app notification is shown while adding item
        Tapping on the notification takes to shopping list and shows syncing animation if user is logged in
        Product count reflects correct quantity
