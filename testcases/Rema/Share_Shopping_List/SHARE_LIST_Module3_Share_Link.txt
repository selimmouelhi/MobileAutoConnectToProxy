SHARE_LINK-01 | Share sheet displays three rounded share link buttons [P0]
    Preconditions
        User is logged in to the Rema 1000 app
        User has navigated to a shopping list
        Share shopping list sheet is presented and fully loaded
    Actions
        Observe the bottom section of the share shopping list sheet
        Identify the share link buttons displayed
        Verify the count and labels of the buttons
    Expected
        Three rounded buttons are displayed in the share sheet footer area
        The first button is labeled with text matching localization key app_share_list.share_footer_qr_code
        The second button is labeled with text matching localization key app_share_list.share_footer_share_link
        The third button is labeled with text matching localization key app_share_list.share_footer_copy_link
        No raw localization key strings are displayed
        All three buttons are visible without scrolling
    API
        N/A

        No raw localization key strings are displayed
    API
        Share link request fails via the Shared KMP module
