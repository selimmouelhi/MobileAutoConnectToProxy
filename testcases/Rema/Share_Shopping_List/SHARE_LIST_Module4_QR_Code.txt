Share Shopping List - Module 4: QR Code

QR_CODE-01 | Tapping QR code button fetches the share link and shows loading state [P0]
    Preconditions
        User is logged in to the Rema 1000 app
        User has navigated to a shopping list
        Share shopping list sheet is presented and fully loaded
        Network conditions allow the share link API request to proceed
    Actions
        Tap the QR code button
        Observe the button state immediately after tapping
        Observe the other two buttons (Share link and Copy link) during loading
    Expected
        The QR code button displays a loading state with a circle spinner within the button
        The Share link button and Copy link button are not clickable during loading
        The loading state persists until the share link is fetched from the Shared KMP module
    API
        Share link is fetched via the Shared KMP module which calls the backend API

QR_CODE-03 | QR code fetch failure shows error alert and exits loading state [P0]
    Preconditions
        User is logged in to the Rema 1000 app
        Share shopping list sheet is presented and fully loaded
        Network conditions are configured to cause the share link API request to fail
    Actions
        Tap the QR code button
        Wait for the request to fail
        Observe the button state after failure
        Observe the error alert that appears
    Expected
        The QR code button exits the loading state (spinner is removed)
        An error alert is presented on top of the share shopping list sheet
        The error alert title displays text matching localization key app_share_list.create_link_error_title (fallback: "Der skete en fejl")
        The error alert message displays text matching localization key app_share_list.create_link_error_message (fallback: "Linket kunne ikke laves. Prøv igen")
        The error alert has an action button matching localization key app_share_list.create_link_error_action (fallback: "OK")
        No raw localization key strings are displayed
    API
        Share link request fails via the Shared KMP module
