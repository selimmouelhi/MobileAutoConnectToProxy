Share Shopping List - Module 5: Accept Invitation

ACCEPT_INV-01 | Deep link opens the app and navigates to invitation sheet [P0]
    Preconditions
        Rema 1000 app is installed on the device
        User taps a deep link in the format https://shop.rema1000.dk/shopping-list-invitation-link/<invitation-id>
        The app is not currently running in the foreground
    Actions
        Tap the deep link from an external source (e.g. messaging app, browser, email)
        Observe whether the Rema 1000 app opens
        Observe the screen presented after the app opens
    Expected
        The Rema 1000 app opens upon tapping the deep link
        The invitation sheet is presented immediately on top of whatever view is shown in the app
        The invitation sheet contains the correct content for the given invitation ID
    API
        getInvitationByUrl(url: URL) is called with the deep link URL
